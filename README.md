# Finite Bit Formalism (FBF) in Coq

This repository contains a formalization of the **Finite Bit Formalism (FBF)** — a constructive, information-theoretic axiomatic system for reasoning in Euclidean geometry and number theory.

Developed by **Manouchehr Amiri**, this Coq library encodes the foundational axioms, reasoning steps, and key geometric theorems in a bit-conservative formal logic framework.

## Contents

- `src/FBF_Basics.v` — Core definitions: Bits, contexts, and formal axioms.
- `src/FBF_Geometry.v` — Encodings of basic geometric structures (e.g. triangles, medians).
- `src/FBF_Theorems.v` — Examples: triangle congruence, concurrency theorems.
